# Release acceptance inventory

Run the packaged production extension in the official VS Code ExtensionHost. Drive the real panel DOM and native dialogs in its Electron process. Save captures and request/asset receipts to the external SSD. Label controlled transport cases explicitly; never describe them as live generation.

| Visible function | Required check | Transport |
| --- | --- | --- |
| Open Media Studio | Eight commands registered; real panel loads CSS and script; CSP has no violation | Actual ExtensionHost |
| No-key onboarding | Account CTA, secure connection action, API-paid disclosure and disabled generation | Actual UI |
| Set / change key | Native password input; only stored-key boolean reaches panel | Actual SecretStorage |
| Account resources | Correct site, model catalog, API keys, usage and docs routes open | Actual native links |
| Image / edit / video tabs | Correct controls and explicit suggested model; exact typed model retained | Actual UI |
| Prompt and advanced parameters | Valid inputs submitted; malformed or reserved parameters fail before POST | Actual UI; local validation |
| Image generation | One POST, terminal success, visible decoded image, task ID | Live HTTP |
| Reference selection | Native dialog, real selected-byte hashes, visible thumbnails | Actual UI/files |
| Reference editing | Preserve reference subject while making requested change | Live HTTP |
| Multiple references | Both selected references arrive and affect result, using a qualified exact model | Live HTTP |
| Mask qualification gate | No visible mask picker; public mask messages/parameters are rejected before POST | Actual UI / controlled input; upstream qualification failed |
| Video generation | One POST, progress, decoded preview with duration/resolution | Live HTTP |
| Stop waiting | Stops local GET polling; explicit upstream-charge boundary; no cancel/POST retry | Controlled queued fixture |
| Task history and manual recovery | Resume a prior live task by ID; no new POST | Live GET |
| Image/video preview | Image natural dimensions and video metadata load in Webview | Actual Webview |
| Save to project | Native save dialog; output hash matches preview; existing files not overwritten | Actual UI/files |
| Authentication failure | Friendly 401 result without exposing key or repeating POST | Controlled 401 fixture |
| Duplicate generation | Busy state blocks a second click while first unresolved | Actual UI |
| Remove key | No-key state returns; generation disabled | Actual SecretStorage/UI |
| Wide / narrow layout | Screenshots and bounds checks: no horizontal clipping, reachable actions, usable controls | Real Electron window |
| Close panel | Local polling aborts, per-panel cache removed; saved files retained | Actual ExtensionHost |

Keep the initial Grok edit failures in private evidence. Recommend `gemini-3.1-flash-image` for reference editing. Do not qualify a model based only on an HTTP success or downloadable file.
